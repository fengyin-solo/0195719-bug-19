```bash

# 或直接用浏览器打开 frontend-user/index.html
```

## 题目内容

制作一个面向中学生的交互式光学设计编程项目，要求以html格式开发 确保简洁易用 包含各种形状和材料的透镜 例如非球面透镜 低色散镜片 高折射率镜片等 具有可视化操控界面和2D光路实时渲染 系统应有第一次打开的引导界面和跨设备兼容性

## 项目介绍

面向中学生的交互式光学设计学习工具，通过可视化方式帮助学生理解透镜成像规律。

### 核心特性

- 透镜类型：凸透镜、凹透镜、平面透镜、非球面透镜
- 特殊材料：低色散镜片、高折射率镜片、普通玻璃
- 2D光路实时渲染（Canvas 2D API）
- 首次使用引导界面
- 跨设备响应式布局（手机、平板、电脑）

### 光路规律

- 凸透镜（球面）：光线向光轴会聚，边缘光线偏折偏强，会聚点略近（约 13% 球差）
- 凹透镜：光线向外发散，反向延长线交于虚焦点
- 平面透镜：不偏折
- 非球面透镜：边缘表面更平，补偿球面的过度偏折，不同高度的平行光会聚到同一焦点
- 偏折按当前折射率与光波长实时计算：蓝光折射率大、焦距短，红光折射率小、焦距长
- 焦点 F 标记与实际光路追迹使用同一公式，标记位置即真实会聚点

### 未穿过镜片的提示

光线全部落在透镜孔径之外、透镜离光源过近或光线不朝向透镜时，画布下方会显示原因并提供“重新检测光路”按钮，调整后可直接重试。

### 自动保存

透镜位置、参数、光源模式与光路运行状态会自动保存到浏览器本地；刷新或重新进入页面后恢复，F 标记位置由物理公式确定性计算，保持一致。

## 测试

物理模型与光路追迹使用 Node 原生脚本验证（无第三方依赖）：

```bash
node test/physics.test.js   # 非球面共焦、球差方向、色散折射率、材料恢复
node test/renderer.test.js  # 实际追迹交点与 F 标记一致、未命中原因
node test/app.test.js       # 启动链路、参数面板联动、刷新恢复、重置
```
